# 🚀 Development Rules

## 🌿 Branching
- Always create branches from **`dev`**
- **Branch naming convention:**
  - `feature-{featureName}-{yourName}` — for new features  
  - `fix-{featureName}-{yourName}` — for bug fixes

## 🔁 Pull Requests
- Open a **PR into `dev`** once your work is complete  
- Ensure your code **builds and passes all tests** before requesting review  
- Keep PRs **small and focused** on a single change
