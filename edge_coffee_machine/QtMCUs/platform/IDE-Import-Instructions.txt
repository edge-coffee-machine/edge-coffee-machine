Instructions for importing the exported platform into a 3rd party IDE
=====================================================================

Due to Qt for MCUs depending on link time optimization you have to
use the exact same compiler that the libraries have been built with:

     riscvgcc version 13.2.0

Import all source files from /home/balsarakocevic/Music/edge-coffee-machine-dev-qmlexporter-build/edge_coffee_machine/QtMCUs/platform to your project.

Compile and link settings
-------------------------

Apply these settings to your build in the IDE:
    Link options: -Wno-psabi
    Static libraries to be linked:
                           ${QUL_DIR}/lib/libQulCore_riscv32-esp32-p4_Linux_riscvgcc_MinSizeRel.a
    Compile options for all files: -fno-exceptions -fno-non-call-exceptions -fomit-frame-pointer $<$<COMPILE_LANGUAGE:CXX>:-fno-rtti> $<$<COMPILE_LANGUAGE:CXX>:-fno-threadsafe-statics> $<$<COMPILE_LANGUAGE:CXX>:-fpermissive> -fno-common -fno-asynchronous-unwind-tables -fno-unwind-tables -MMD -MP
    Compiler defines:
                           QUL_FREERTOS_TASK_PRIORITY=CONFIG_QUL_FREERTOS_TASK_PRIORITY
                           QUL_PLATFORM_DEFAULT_NUM_FRAMES_TO_PRESERVE_ASSETS=0
                           QUL_PLATFORM_DEFAULT_TEXT_CACHE_ENABLED=0
                           QUL_PLATFORM_DEFAULT_TEXT_CACHE_SIZE=24576
                           QUL_PLATFORM_NAME="esp32-p4-func-idf"
                           QUL_PLATFORM_RENDER_BATCH_HEIGHT=0
                           QUL_PLATFORM_REQUIRED_IMAGE_ALIGNMENT=4
                           QUL_PLATFORM_REQUIRED_PIXEL_WIDTH_ALIGNMENT=1
                           QUL_STACK_SIZE=CONFIG_QUL_STACK_SIZE
    Include paths:
                           ${QUL_DIR}/src/3rdparty/minihdlc/
                           ${QUL_DIR}/src/3rdparty/nanopb/
                           ${QUL_DIR}/src/3rdparty/qoi/
                           boards/espressif/common
                           boards/espressif/esp32-p4-func-idf
                           platform/common/
                           platform/common/linux
