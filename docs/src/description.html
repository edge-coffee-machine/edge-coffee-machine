Edge Coffee Machine (ECM)

Smart Coffee Machine featuring Edge AI

The Edge Coffee Machine (ECM) is an AI-driven embedded system designed to demonstrate the power of Edge AI on microcontrollers. The project aims to showcase how technology can respond to human needs by recognizing users, remembering their individual preferences, and offering a personalized coffee experience that feels natural and effortless. By running AI directly on the device, the ECM ensures instant responses, enhanced data privacy, and energy-efficient performance without cloud dependency.

Key Features

  • Facial Recognition: Automatically detects and recognizes users through an integrated camera to trigger personalized sessions.
  • Smart User Classification: Categorizes users into "Default," "Conservative," or "Early Adopter" profiles based on their historical drink choices and customization habits.
  • Adaptive Recommendation Engine: Uses an exponential decay model to prioritize favorite drinks or suggest new ones based on the user's classification.
  • Voice Command Interface: Allows hands-free operation to start the brewing process or select drinks via locally processed speech recognition.
  • Customizable Brewing: Offers precise touch-based adjustment of ingredients including coffee beans, cocoa powder, water, milk, and foam.
  • Privacy-Centric Design: All biometric processing (face and voice) occurs strictly on-device to ensure user data protection.

Architecture & Technology Stack

The ECM is built as a Modular Monolith. The architecture is logically decomposed into three primary layers: a Presentation Layer (UI), a Business Logic Layer (Backend), and a Service Layer (AI component).

  • Hardware: Espressif ESP32-P4-Function-EV microcontroller featuring a dual-core processor and a Neural Processing Unit (NPU).
  • Frontend: Qt for MCU (QML) for high-performance, smartphone-like user experiences on embedded hardware.
  • Backend: C++ using the Espressif IoT Development Framework (ESP-IDF).
  • Edge AI: ESP-DL for face detection and recognition, and ESP-SR for optimized voice command processing.
